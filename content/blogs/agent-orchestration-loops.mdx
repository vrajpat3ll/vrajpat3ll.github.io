A running collection of observations from building Orion.

## The claim

An agent's reliability depends more on the shape of its tools and loop than on
the length of its instructions. An explicit loop of edit, run, read, and decide
keeps failures local and recoverable.

## Notes so far

- Fewer tools, each with a clear contract, work better than many tools with
  overlapping behaviour.
- An agent that can observe the result of every action can correct itself before
  continuing.
- The prompt should describe constraints, not procedure.
